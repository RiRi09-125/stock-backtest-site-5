# 台股策略回測小站（繁體中文版｜自選衛星股）

## 功能
- 核心持股固定為 0050 元大台灣50。
- 可在左側輸入兩支台股衛星股代號，例如 2330、2882；不需輸入 `.TW`。
- 預設配置為 0050 70%、衛星股一 15%、衛星股二 15%。
- 提供買進持有、A1-Q、A1-H、A2、B1、B2 策略的回測原型、績效比較圖與交易紀錄 CSV。

## 部署
此專案可部署到 Streamlit Community Cloud。主程式為 `app.py`。

## 注意事項
- 股票歷史資料由 Yahoo Finance (`yfinance`) 取得，資料可用性及代號支援狀況會影響回測。
- 代號輸入目前以數字台股代號為主，程式會自動加上 `.TW`；不支援 `.TWO` 上櫃股票代碼自動判斷。
- 目前回測屬研究原型，未完整處理股利、除權息、股票分割、滑價等因素；結果不構成投資建議。
- A、B 策略的回測假設請以網站內「策略規則與假設」為準，正式研究前仍建議以人工案例驗算交易邏輯。
